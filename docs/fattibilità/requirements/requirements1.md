# Requirement 1 — Analisi della Concorrenza e delle Best Practice

L’analisi della concorrenza è stata svolta confrontando PsyPlatform con altre piattaforme di psicologia online presenti sul mercato. L’obiettivo è identificare funzionalità utili, elementi apprezzati dagli utenti e best practice applicabili al progetto.

## Obiettivi dell’analisi
- Identificare le funzionalità considerate standard nel mercato.
- Individuare punti di forza dei competitor da replicare.
- Individuare debolezze da evitare.
- Estrarre best practice per migliorare l’esperienza utente.

## Piattaforme analizzate
- **Serenis.it**  
- **Unobravo.com**  
- **Theraplatform.com**

## Confronto sintetico

| Piattaforma | Punti di Forza | Punti di Debolezza | Best Practice Ricavate |
|------------|----------------|---------------------|-------------------------|
| Serenis | Interfaccia moderna, onboarding semplice | Costi elevati | UI minimalista, questionario iniziale |
| Unobravo | Servizio diffuso, gestione appuntamenti efficiente | Interfaccia poco personalizzabile | Integrazione calendario + messaggi |
| Theraplatform | Strumenti professionali integrati | UI molto complessa | Videocall con funzioni cliniche |

## Best practice identificate
- Interfaccia chiara, moderna e intuitiva.  
- Onboarding guidato per nuovi utenti.  
- Calendario integrato con notifiche automatiche.  
- Videochiamate sicure direttamente nella piattaforma.  
- Organizzazione semplice delle note cliniche.  
- Evitare sovraccarichi di funzionalità inutili.

## Requisiti derivati
- UI minimal e intuitiva.  
- Sistema integrato prenotazioni + notifiche.  
- Archivio sicuro per note cliniche.  
- Messaggistica interna criptata.  
- Videochiamata stabile con crittografia.  
- Dashboard semplice per lo psicologo.
